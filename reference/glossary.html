Pretraining Glossary

The words every lesson in this course uses. When the field uses several names for one thing, this page picks one.

Inputs to the model

Token ID
An integer index into the vocabulary produced by the tokenizer. It is the only thing the embedding layer sees.
Special token
A token ID reserved for a control symbol (EOS, <assistant>) that ordinary text never tokenizes into.
Position ID
The integer each token's RoPE rotation is computed from. By default it equals the token's index, but it's a separate input that can differ (see aliasing).
Avoid: "position", when you mean the index
Index
A token's physical slot in the sequence array (0…S−1). In this course, "index" and "position ID" are never used interchangeably.
Attention mask
A boolean [query, key] matrix that says which tokens a token may see. Blocked scores are set to −∞ before the softmax.
Loss mask
A per-position weight in {0, 1} that says which next-token predictions the model is trained to produce. Levanter calls it loss_weight.
Avoid: "label mask", "ignore mask"

SPP

Reflection
A short (≤128-token) first-person, constitution-grounded passage inserted into an annotated document, preceded by <assistant>.
Insertion point (n)
The index where <assistant> is placed. The reflection is conditioned only on the tokens before it.
Pre-context / post-context
The document tokens before and after the reflection block.
Aliasing (RoPE aliasing)
Giving post-context tokens position IDs that restart at n, so their relative distances to the pre-context match a document with no reflection.
Reflection block mask
The SPP attention-mask edit: post-context queries can't attend to reflection-block keys.
Compact / annotated stream
Compact: ordinary documents packed densely into windows. Annotated: one reflection-eligible document per padded window.

TPP

MFU
