Compute Budget Sheet

Napkin math for sizing a pretraining run.

Core formulas

matmul (N×P)(P×M) = 2NPM FLOPs
train C ≈ 6·N·Dfwd 2 + bwd 4 per param per token
D = TPP · N ⇒ C = 6·TPP·N²
time ≈ C / (chips · peak · MFU)

Corrections and rules of thumb

  • Attention FLOPs / matmul FLOPs ≈ T/(8·dmodel).
  • Block remat → about 8ND actual FLOPs.
  • Check whether N includes embeddings (Kaplan 2020 excluded them).
  • Chinchilla ≈ 20 TPP (70B on 1.4T). Plan with about 40% MFU.
